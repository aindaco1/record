Verified September 23, 2026 on Apple Silicon running macOS 27.0 (26A428).

## Source and release gates

modules, conservative transcript cleanup and synthetic development evaluator.
The signed annotated `v1.4.5` tag identifies
`e5edc723d62b98697d5197632a51e284028bc25e`.

- The full local gate passed on that exact main commit: 351 Swift cases with
  two expected skips, zero failures, ASan, TSan, source/privacy contracts,
  package checks and the signed test feed. The skips cover the explicit native
  quality probe and an external multitrack-media fixture; quality ran separately.
- [Full CI](https://github.com/aindaco1/record/actions/runs/35895002389) and
  [CodeQL](https://github.com/aindaco1/record/actions/runs/35895002199) passed.
  CodeQL attempt 1 failed while spawning the package manifest with a CPU-type
  error; attempt 2 passed without source or gate changes. No open code-scanning
  alerts remained before tagging.
- [Release workflow](https://github.com/aindaco1/record/actions/runs/35926902296)
  reused the attested CI app, signed, notarized and published
  [1.4.5, build 22](https://github.com/aindaco1/record/releases/tag/v1.4.5)
  at 22:14 UTC. It retains arm64, macOS 15.0 minimum, Xcode 27.0 (27A266a)
  and Swift 6.4.
