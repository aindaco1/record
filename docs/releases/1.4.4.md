# Record 1.4.4

Record 1.4.4 updates the signed application updater to Sparkle 2.10.0,
including its macOS 27 installer and file-handling improvements.

The update preserves Developer ID signing, notarization, signed update feeds
and archives, and Record's stable privacy identity. The sandboxed main app
still has no network entitlement; application update networking stays in
Sparkle's reviewed downloader service. Recordings, screenshots, transcripts
and metadata remain local, with microphone and system audio kept separate.

This release is built with released Xcode 27.0 and Swift 6.4. Required build,
security and package checks use the same pinned compiler, and release signing
reuses the exact application that passed CI. It also includes reviewed CodeQL
updates, the current Apple Intelligence sampling API, and safer shared Podman
watchdog behavior for local development.

macOS 15 or newer and Apple Silicon remain required. The
[macOS 27 readiness report](../testing/macos-27-readiness.md) records build
evidence and toolchain policy. Remaining manual and hardware checks continue
in [issue #6](https://github.com/aindaco1/record/issues/6); this maintenance
release does not mark those untested scenarios as passing.
