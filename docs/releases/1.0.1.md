# Record 1.0.1

Record 1.0.1 is a focused reliability and setup release.

## Highlights

- Record now detects a missing default Parakeet model and guides users through
  downloading it from FluidInference's pinned source and importing it locally.
  Every required file is size-checked and SHA-256 verified before an atomic
  install; recording continues to work while the model is absent.
- Open at Login no longer incorrectly claims that Record must be moved to
  Applications when macOS reports an unregistered main-app service.
- MacWhisper is shown only when the MacWhisper app, bundled `mw` CLI, and
  Record's sandbox bridge are present.
- Release automation now rejects any change to Record's persistent macOS
  privacy identity before publishing an update.
- A scoped FluidAudio pull request explicitly excludes Parakeet benchmark
  documentation from SwiftPM source discovery. Record will consume it after an
  upstream release rather than depending on an application-specific fork.

## Upgrade notes

Install over Record 1.0.0 with **Check for Updates…** or the notarized DMG.
Existing Screen & System Audio Recording, System Audio Recording Only, and
Microphone grants should remain associated with `com.aindaco.record` because
the bundle identifier, Apple team, and designated requirement are unchanged.
The release checklist verifies this identity and includes a manual 1.0.0 to
1.0.1 permission-retention test.

Parakeet models already present in Record's sandbox are reused. If no model is
present, follow the new setup prompt; Record never uploads recordings or sends
model-download traffic itself.
