# Record 1.1.3

Record 1.1.3 is a security and dependency maintenance release for Apple
Silicon Macs running macOS 15 or newer.

## Update security

Sparkle is updated from 2.9.5 to 2.9.6. The upstream release hardens installer
archive movement and rejects package-based installation after signing
validation fails. Record continues to require an explicit **Check for
Updates…** command, Ed25519-signed update metadata and archives, Developer ID
signing, and Apple notarization. Sparkle's sandboxed helper services remain the
only update network path; the main Record app retains no incoming or outgoing
network entitlement.

## Local speech and build maintenance

FluidAudio is updated from 0.15.5 to 0.15.6 for its current offline Parakeet
and speaker-diarization maintenance. Record still blocks FluidAudio's download
entry points, loads only an already-present verified model, and keeps all
recordings, transcripts, models, diagnostics, and session metadata local.

The pinned CodeQL action is updated from 4.37.6 to 4.37.7, including CodeQL
bundle 2.26.3. All workflow actions remain pinned by full commit revision.

## Tracker status

This release integrates pull requests
[#50](https://github.com/aindaco1/record/pull/50) and
[#48](https://github.com/aindaco1/record/pull/48). The remaining open issues
are signed-app and representative-hardware acceptance trackers for features
already shipped; this dependency release does not claim those macOS 27, USB,
Bluetooth, source-loss, or force-quit rows as completed.
