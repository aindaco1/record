# Record 1.4.2

Record 1.4.2 updates its local Parakeet speech runtime to FluidAudio 0.15.7 and
keeps the build and packaging checks working with Xcode 27 / Swift 6.4.

- On-device transcription uses the reviewed FluidAudio 0.15.7 dependency.
  The main app retains its sandbox and has no network entitlement.
- Swift Build packaging is checked with Xcode 27 alongside the stable release
  toolchain. Release package tools are restored from the pinned dependency graph.
- GitHub Actions dependencies are updated to their reviewed pinned revisions.

A Developer ID signed candidate was exercised on an Apple Silicon Mac running
macOS 27.0. A real screen recording exported HEVC video and independent 24-bit
PCM microphone and system-audio tracks. Repeated pause/resume preserved the
paused elapsed counter. Audio-only recording finalized both audio tracks.
Parakeet transcription completed while another app was active, recognized the
synthetic speech markers, and used Apple's on-device readability adviser.

The complete local gate passed 342 tests with one expected external-fixture
skip, sanitizers, packaging and signed test-feed validation. These results cover
this host and the scenarios exercised; the
[macOS 27 tracker](https://github.com/aindaco1/record/issues/45) retains separate
permission-reset, device-route, multi-display and updater acceptance items.

Record remains local-only. Original capture segments are preserved until the
complete exported session has been validated. Video, microphone and system
audio remain separate files.
