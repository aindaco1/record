# Record 1.5.1

## Fixed

- Audio-only recording and dictation now automatically turn off Apple voice processing while the native Zoom app is open. This avoids a shared microphone format change that can make your voice very quiet in Zoom when using the built-in microphone.
- If Zoom opens during a recording, Record switches to raw microphone input for the rest of that recording. Apple voice processing resumes on a later recording after Zoom quits.

## Changed

- Settings → Recording includes **Use Apple voice processing** and **Turn off while Zoom is open**, both enabled by default. You can turn either option off independently.
- Automatic microphone gain control is off by default. Enable **Automatically adjust microphone volume** in Recording settings when wanted.

Zoom detection includes the app running in the background. Raw microphone input may capture more speaker echo or background noise. These controls apply to audio-only recording and dictation with System Default selected; screen recording and explicitly selected microphones retain their existing capture paths.
