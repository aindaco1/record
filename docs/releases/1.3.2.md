# Record 1.3.2

Record 1.3.2 fixes the final installation step for the one-click Parakeet model
setup introduced in 1.3.1.

## Parakeet setup fix

The pinned model pack includes attribution and license files in an outer
`Record-Parakeet-v3-aed0274` directory. Record 1.3.1 downloaded, verified, and
expanded that exact archive, but its automatic installer did not enter the
outer directory before looking for `parakeet-tdt-0.6b-v3`.

Record now recognizes the fixed published wrapper layout and passes the inner
model folder through the existing 17-file size/SHA-256 checks and atomic local
installer. The model asset, checksum, manual-import path, and network boundary
are unchanged.

## Network boundary

The main Record process remains network-denied. The dedicated sandboxed XPC
service still chooses only the compile-time-pinned GitHub asset, accepts only
GitHub-controlled HTTPS redirects, verifies the archive before returning bytes
through a private file descriptor, and receives no recording, transcript,
clipboard value, URL, path, identifier, diagnostic, or session metadata.
