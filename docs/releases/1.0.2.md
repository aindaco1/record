# Record 1.0.2

Record 1.0.2 is a small quality-of-life and recovery release. It deliberately
does not add a new capture mode, editor, account, or network service.

## Highlights

- **Open last recording** reveals the newest finished session even after Record
  relaunches. The answer is derived from validated local `session.json` files;
  Record does not create a separate history or activity database.
- A failed local transcription now exposes **Retry Failed Transcription** in
  the Transcription Model submenu. Retrying leaves both source audio files
  unchanged.
- Startup recovery posts one human-readable summary when it preserves an
  interrupted recording, marks an empty session failed, or finds a manifest
  that needs review. The notification contains no recording name or content and
  opens Record's temporary recovery storage.
- The active GitHub backlog now tracks concrete reliability work. Larger ideas
  such as an editor, camera overlay, browser bridge, first-party Whisper, and a
  general plugin host are parked in the ROADMAP until a real need justifies
  them.

## Upgrade notes

Use **Check for Updates…** in Record 1.0.1 or install the notarized DMG. Record's
bundle identifier, Apple signing team, sandbox, and designated requirement are
unchanged, so existing privacy grants remain associated with the same app.

No recording, transcript, model, clipboard value, diagnostic, or recent-item
index is uploaded. Sparkle's reviewed update service remains Record's only
network-capable component.
