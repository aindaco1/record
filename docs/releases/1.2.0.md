# Record 1.2.0

Record 1.2.0 adds optional, on-device Apple Intelligence assistance for more
readable local transcripts on supported Apple Silicon Macs running macOS 26 or
newer. Record itself continues to support macOS 15 and newer.

## On-device transcript refinement

When **Transcript model → Improve Transcript Readability** is enabled and
Apple's Foundation Models framework is available, Record asks the on-device
model to classify only bounded filled-pause and immediate-repeat candidates.
Record does not permit free-form rewriting: deterministic validation preserves
timestamps, speaker labels, and source tracks, while overlapping speakers are
marked explicitly in JSON and Markdown exports.

If Apple Intelligence is disabled, unavailable, unsupported for the current
language, or generation fails, ordinary local transcription still completes.
The option is off by default.

When refinement changes the readable transcript, Record keeps the complete
pre-refinement result in `transcript.raw.json`. It also writes a content-free
`transcript.refinement.json` report containing the policy version, source hash,
capability outcome, validated decisions, and overlap count without copying
transcript text.

## Privacy and compatibility

Foundation Models processing stays on-device. Record adds no account, upload
client, cloud transcription, model download, analytics, or main-app network
entitlement. The release retains the macOS 15 deployment target and weak-links
the macOS 26 framework so unsupported Macs continue to use ordinary local
transcription.

The authoritative build and release jobs now select Xcode 26.3 explicitly,
while the existing Xcode 27 compatibility lane remains advisory.
