# Record 1.3.1

Record 1.3.1 makes local Parakeet transcription setup a single explicit action
without granting the main recording process network access.

## Download and install from Settings

Open **Settings… → Recording → Set Up Parakeet Model…** and choose **Download
and Install**. Record downloads the existing pinned Parakeet v3 model pack from
its GitHub release, verifies the archive and all 17 expected model files, and
installs only those files into private local storage. Pending transcription
resumes automatically when setup completes. Recording continues normally when
the model is absent or a download fails.

Transient connection loss uses bounded retry/resume. Manual import remains
available for offline setup or recovery.

## Network boundary

The main Record process retains no incoming or outgoing network entitlement.
The model request runs in a new sandboxed XPC service whose entitlements contain
only App Sandbox and outbound network access. The service chooses a fixed,
compile-time-pinned GitHub URL and receives no caller-provided URL, local path,
recording, transcript, clipboard value, identifier, diagnostic, or metadata.

The helper accepts only HTTPS redirects within GitHub-controlled hosts and
verifies the exact archive byte count and SHA-256 before returning bytes through
a private file descriptor. Record independently repeats archive verification,
then reuses its existing per-file checks and atomic local installer. FluidAudio
remains offline.

## Distribution

The model remains a separate release asset. It is not added to Git, Record.app,
the DMG, or the routine Sparkle update archive, so existing users download the
roughly 466 MB model only when they explicitly request transcription setup.
