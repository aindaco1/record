# Record 1.2.3

Record 1.2.3 is a local-safety and maintainability release for Apple Silicon
Macs running macOS 15 or newer.

## One session-media contract

Audio-only recording, screen recording, finalization, recovery, inspection,
transcription, export, and local handoff now share one canonical definition of
Record's media filenames and anonymous speaker defaults. The on-disk session
format is unchanged: completed sessions still use `recording.mov`, `mic.wav`,
`system.wav`, and `session.json`; private crash-recovery audio remains CAF until
the completed WAV export validates.

Every recording menu phase also applies one complete control presentation.
Conflicting mode, source, export-folder, and capture-privacy changes remain
disabled throughout permission, preparation, pause/resume, stop, and save
transitions instead of inheriting whatever a prior phase happened to set.

## Local artifact safety

A shared local-file policy now requires recording artifacts to be real,
non-symlink files before audio inspection, Gifski handoff, recent-video
restoration, session export, media concatenation, or interrupted-session
recovery accepts them. This keeps those local boundaries consistent without
changing Record's privacy model or adding any network path.

## Release maintenance

The commit-pinned CodeQL action advances from 4.37.7 to 4.37.9 with CodeQL
bundle 2.26.4. The release workflow also restores Sparkle's locked
`generate_appcast` tool before producing the signed update feed from the exact
CI-tested app.

Record still has no accounts, analytics, upload client, cloud transcription,
model download, or main-app network entitlement. Sparkle's reviewed sandboxed
services remain the only update network path, and installation remains
user-approved.
