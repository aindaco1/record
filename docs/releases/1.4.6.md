# Record 1.4.6

Record now uses Dust Wave Platform's shared Sparkle controller and launch policy.
Update checks, user-approved installation and login launch behavior retain their
existing settings. The pinned dependency makes fixes reusable across Dust Wave
apps while keeping Record's update networking inside Sparkle's downloader service.

Recordings, transcripts, screenshots and diagnostic data stay local. This release
does not add report submission or change capture, transcription or cleanup policy.
Development checks distinguish product failures from incomplete evaluator results.

See the [migration record](../SHARED_DESKTOP_MIGRATION.md) for source validation and
rollback instructions. Signing, downloaded-artifact and updater acceptance are
recorded separately by the release workflow.
