# Record 1.1.2

Record 1.1.2 makes first installation clearer while preserving the existing
local-only application, recording, transcription, update, and privacy-identity
contracts.

## Simpler installation

The notarized DMG now presents exactly one **Record** app and an Applications
shortcut. Drag Record onto Applications, eject the image, and launch the
installed copy. The conventional single-app layout also works with cautious
automatic DMG handlers such as EasyDMG without making one a required dependency.

The README links directly to the Apple Silicon DMG. The full GitHub release
continues to provide release notes, SHA-256 checksums, build metadata, and
provenance.

## Stronger release verification

Packaging, local package checks, and post-notarization validation share one
exact DMG layout contract. The release job verifies image integrity, mounts the
final image read-only in a private temporary directory, rejects unexpected
top-level entries or redirected shortcuts, and rechecks the mounted app's
bundle structure, signatures, entitlements, stable TCC identity, notarization
ticket, and Gatekeeper result before generating update metadata.

These checks do not inspect or process recordings, transcripts, clipboard
values, diagnostics, session metadata, or imported models.
