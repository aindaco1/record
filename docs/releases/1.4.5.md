# Record 1.4.5

Record 1.4.5 improves optional on-device transcript cleanup. It removes more
disposable fillers while protecting quotations, intentional emphasis and
grammatical repetition such as “had had.” Apple's general model advises on
eligible removals; deterministic rules preserve quoted segments, sentence
boundaries, longer repetition runs and overlapping speech.

Cleanup still removes only complete source tokens. It preserves the raw
transcript when edits are made, speaker labels, timestamps and original media.
Conservative rules may leave extra fillers or stutters when their removal is
uncertain. Existing sessions are not reprocessed.

The release adopts Dust Wave Platform's shared local speech and Apple
Intelligence adapters, retaining Record's existing transcription engines,
model verification and offline behavior. Recordings, screenshots, transcripts
and metadata remain local. The main app gains no network access.

Developer tests now combine deterministic checks with native Apple cleanup
and Jev review of pinned synthetic examples. Both product suites passed in the
[cleanup evaluation](../testing/cleanup-fix-2026-09-23.md); known judge-control
mismatches remain visible and do not weaken release checks. Jev is not shipped
in the app and never receives recordings or private transcripts.

macOS 15 or newer and Apple Silicon remain required. Optional Apple Intelligence
cleanup requires a supported system and available model. Remaining physical
hardware and clean-account acceptance continue in
[issue #6](https://github.com/aindaco1/record/issues/6); this release does not mark
those untested scenarios as passing.
