# Record 1.0.3

Record 1.0.3 is a capture-reliability and recovery release for Apple Silicon
Macs running macOS 15 or newer.

## Highlights

- Microphone and system-audio capture no longer encode or write files on the
  real-time callback. Fixed-capacity queues bound memory and report pressure or
  write failures without recording content in diagnostics.
- Record detects default microphone and audio-engine route changes, coalesces
  duplicate notifications, restarts the microphone into the same file, retries
  recoverable failures, and pads downtime so timestamps do not collapse.
- Apple's on-device voice processing is enabled by default. Residual speaker
  bleed is removed only from high-confidence duplicated transcript segments;
  raw audio is unchanged and `transcript.raw.json` preserves the unsuppressed
  local result.
- Startup recovery validates media containers, promotes playable writer
  partials, and moves invalid partials intact to `Recovery/Corrupt Media`.
- The menu labels are now **Transcript model** and **Select export folder…**.

## Upgrade notes

Use **Check for Updates…** in Record 1.0.2 or install the notarized DMG. The
bundle identifier, signing team, sandbox, entitlements, and designated
requirement remain unchanged so macOS can associate the update with existing
privacy grants.

Record remains strictly local-only. Raw tracks, transcripts, capture health,
models, and recovery artifacts never leave the Mac. Sparkle's sandboxed,
explicit update check remains the only network-capable component.
