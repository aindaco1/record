# Record 1.5.0 (unreleased)

Candidate release implementing the six high-priority improvements from the
[Handy review](../project/handy-review-2026-10-02.md).

- Choose a microphone and record microphone only, system audio only, or both.
  Test input without saving a recording and see independent source activity.
- Retry incomplete transcription without repeating successful tracks. Partial
  transcripts are marked clearly; Transcribe later preserves work across launches.
- Browse Recent Sessions from the current save folder and private recovery
  storage, preview or copy clean/raw transcripts, play sources, and retry work.
- Configure global screen/audio start-stop and screen pause-resume shortcuts.
  Existing screenshot shortcuts remain unchanged; new recording shortcuts start Off.
- Return to a Ready to Record checklist and follow model download, verification,
  and installation progress. Cancel setup without losing a prior installed model.
- Use a compact recording panel with elapsed time, source activity, pause, and stop.
  It appears automatically and can be disabled in Audio settings.

No account, cloud transcription, analytics, or general network access is added.
See [ADR 0026](../adr/0026-local-recording-workflow.md) for local storage and recovery
semantics. This candidate has not been published. Validation and hardware acceptance
are tracked separately in [candidate testing](../testing/1.5.0-candidate.md).
