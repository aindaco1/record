# Record 1.1.0

Record 1.1.0 adds private screen-source selection and crash-safe recording
pause and resume for Apple Silicon Macs running macOS 15 or newer.

## Highlights

- Choose the main display, use Apple's system picker for a display,
  application, or window, or select a custom region on one display.
- Pause and resume screen recordings while keeping video, system audio, and
  microphone audio as independent, recoverable tracks.
- Record writes immutable numbered segments while capturing. Final export
  joins compatible HEVC video without re-encoding and remuxes AAC packets into
  the canonical microphone and system-audio files.
- The captured-time counter excludes pauses and restart gaps, so it reflects
  the duration of the resulting recording.
- Interrupted sessions retain their segments for startup recovery instead of
  deleting partially captured media.
- CI now checks Xcode 27, Swift 6.4, and the macOS 27 SDK while Record keeps its
  macOS 15 deployment target and stable release toolchain.

## Privacy and upgrade notes

System-picker selections are memory-only. Record saves the chosen mode but
does not persist application names, window titles, source identifiers, or
region geometry. Pause journals contain only local filenames, segment indices,
track kinds, and relative times.

Use **Check for Updates…** in Record 1.0.3 or install the notarized DMG. The
bundle identifier, signing team, sandbox, entitlements, and designated
requirement remain unchanged so macOS can associate the update with existing
screen, system-audio, and microphone privacy grants.

Record remains strictly local-only. Captured media, transcripts, source
metadata, models, and recovery artifacts never leave the Mac. Sparkle's
sandboxed updater remains the only network-capable component.
