# Record 1.2.2

Record 1.2.2 makes completed audio tracks easier to move into editing tools.
New screen and audio-only sessions contain independent `mic.wav` and
`system.wav` files as uncompressed 24-bit PCM audio.

## WAV session audio

Record preserves each source's captured sample rate and channel layout while
creating the WAV files. The microphone and system tracks remain separate, keep
their synchronization offsets in `session.json`, and continue to feed the same
local transcription pipeline.

Because uncompressed PCM is larger than AAC, completed sessions use more disk
space and take an additional duration-proportional finalization pass after
recording stops. Existing sessions are not changed.

## Recovery and privacy

Real-time capture and pause/resume still use private AAC/CAF recovery media.
Record creates both WAV files atomically before marking a session complete and
keeps the CAF sources until the exported session has been validated. A failed
conversion or export leaves the private recovery media intact.

All audio conversion remains local. Record adds no account, analytics, upload,
cloud transcription, model download, or main-app network entitlement.

## Release integrity

Record 1.2.2 also reuses the provenance-attested unsigned app from the exact
successful `main` CI commit before applying the release stamp, Developer ID
signature, notarization, packaging, Sparkle signatures, checksums, and
attestation. The signed updater still requires user approval to install.
