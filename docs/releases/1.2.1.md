# Record 1.2.1

Record 1.2.1 checks for signed updates automatically whenever the app opens,
while keeping every download and installation under the user's control.

## Quiet launch checks

Immediately after Sparkle starts, Record performs one silent background check
against the public signed GitHub appcast. The check stays silent when Record is
current. When a newer release is available, Sparkle presents its standard
update prompt so the user can review, defer, or install it.

The existing **Check for Updates…** command remains available as a manual
fallback. Record 1.2.0 still requires that command to discover this release;
automatic launch checks begin after 1.2.1 is installed.

## Privacy and integrity

Automatic installation and Sparkle system profiling remain disabled. Update
requests contain no recording, transcript, clipboard, session, diagnostic,
model, local-path, or account data. The main Record app retains no incoming or
outgoing network entitlement; Sparkle's sandboxed downloader and installer XPC
services remain the only update network path.

Every accepted appcast and update archive remains bound to Record's Ed25519
key. Release artifacts retain Developer ID signing, Apple notarization and
stapling, checksums, stable TCC identity verification, and build provenance.
