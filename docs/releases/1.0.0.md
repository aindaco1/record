# Record 1.0.0

Record 1.0 is the first stable release of the native, local-first macOS menu-bar
recorder.

## Highlights

- Record the main display with independent microphone and system-audio tracks.
- Make audio-only recordings with the same recoverable two-track layout.
- Export complete sessions to Desktop or another approved folder.
- Transcribe locally with Parakeet v3, or explicitly choose an installed
  MacWhisper Small model.
- Hide notifications, the menu bar, or Desktop items from capture; apply safe
  recording-name templates; and hand the last video to Gifski.
- Check for signed updates manually and optionally open Record at login.

Record does not upload media or transcripts and has no accounts or analytics.
The explicit update check contacts only Record's public GitHub release feed.

Requires macOS 15 or newer on Apple Silicon.

See the [changelog](https://github.com/aindaco1/record/blob/main/CHANGELOG.md)
for the complete 1.0.0 list and the
[README](https://github.com/aindaco1/record#readme) for installation and model
setup.
