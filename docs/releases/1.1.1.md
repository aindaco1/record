# Record 1.1.1

Record 1.1.1 fixes crashes in the screen-source workflows introduced in 1.1.0.

## Fixed

- Selecting a display, application, or window in Apple's screen-source picker
  no longer terminates Record.
- Cancelling Apple's picker no longer terminates Record.
- Custom Region now proceeds from display selection to Record's local region
  overlay instead of terminating before the overlay appears. The overlay uses
  an unambiguous display fallback and reliably accepts drag and Escape events.

ScreenCaptureKit delivers these observer callbacks on ReplayKit's XPC queue.
Record now transfers the opaque, memory-only selection to the main actor before
it updates application state. No source names, identifiers, window titles, or
region geometry are persisted.

Use **Check for Updates…** in Record 1.1.0 or install the notarized DMG. Record's
bundle identifier, signing team, sandbox, entitlements, and designated
requirement remain unchanged so macOS can retain existing recording permissions.
